# DocReadyApp feature checklist

## Phase 1 · Workspace

- [x] Shared design tokens, responsive landing page, sidebar and mobile navigation.
- [x] Landing upload handoff, searchable tool catalog, Ctrl/Cmd+K, browser history and settings.
- [x] Original vector brand, bundled typography and reduced-motion support.

## Phase 2 · Document engines

- [x] Merge, split, rotate, reorder and preview PDFs.
- [x] Images to PDF, PDF to JPEG or PNG, scanned-PDF recompression and file-size comparison.
- [x] PDF watermarks, page numbers, text annotations and outlined rectangles.
- [x] Resize, compress, convert, crop, rotate, flip, adjust and batch-process images.
- [x] Inspect common image metadata markers and remove embedded metadata by re-encoding.
- [x] Prepare signatures with a live crop preview and user-entered requirements.
- [x] Draw and export a signature with undo, pen settings and background control.

## Phase 3 · Application Ready

- [x] Generic application templates, document requirements, and explicit local template saving.
- [x] File intake, image resizing and conversion, per-document checking and error recovery.
- [x] Individual downloads and ZIP with a validation summary.

## Phase 4 · Additional workflows

- [x] Four-corner document scanning, camera flow, page ordering and PDF/JPEG export.
- [x] Local OCR for English and Hindi, including mixed text, PDF input, cancellation and editable TXT export.
- [x] Five resume layouts, formatting controls, custom sections, opt-in drafts and selectable-text PDF export.
- [x] File grouping, sorting, name changes, duplicate detection, SHA-256 and ZIP output.
- [x] Browser privacy information, preferences, draft cleanup and OCR cache controls.

## Phase 5 · Release checks

- [x] Static production build and HTTPS hosting instructions.
- [x] Manifest, install icons, offline cache, versioned assets and update UI.
- [x] Type checks, engine tests, browser workflows and visual verification.
- [x] Known limitations recorded in the audit.

## Outside this release

- [ ] Full Hindi interface localization and non-Western resume/PDF overlay font support.
- [ ] Rich-text PDF editing, PDF encryption, secure redaction and Office conversion.
- [ ] Automatic document edge detection and device-specific physical camera validation.
- [ ] Native install and service-worker update UI validation on each browser and OS.
