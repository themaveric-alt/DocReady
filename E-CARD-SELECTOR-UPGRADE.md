# Government e-card selector and crop upgrade

Eight inline SVG preset choices now precede file import: Aadhaar, PAN, EPIC, driving licence, APAAR, ABHA, e-Shram and Other. These are original category symbols rather than official government logos. PDF password handling continues through the existing local PDF.js prompt; passwords are neither logged nor persisted.

Detection uses PDF text positions, whole-page compact-region rejection, OpenCV contours/adaptive thresholds, a saturated-color mask, broken cutting-guide support and evidence-based preset ranking. Presets never create a successful crop on their own. Unknown sides and inferred/borderless crops still require review. Native PDF pages are analysed at up to 300 DPI within a 9MP/5,500px cap, or 150 DPI/3MP on reported 2GB devices. Processing stays sequential; final region renders are independent from analysis resolution. The existing client-side PDF.js worker renderer, OpenCV worker and image workers are reused. Vite serves PDF.js/PDF-lib from local bundled assets alongside the stable `/libs` copies; OpenCV remains in `/libs`.

PDF crop previews now render from source regions at print resolution instead of only cropping a low-resolution page thumbnail. Four-corner manual adjustment, source-page selection, rotation and front/back confirmation are retained. Magic Clarity applies optional conservative sharpening/contrast in a raster worker; the same option is applied during final export. It cannot recover absent text or QR detail. Perspective correction preserves original artwork and print placement uses contain-fit without stretching.

Quick exports provide individual PNG/JPEG crops and an A4 PDF with 85.6 × 54.0mm frames (rounded ID-1), 300 DPI preparation and dashed external cutting borders. The exact 85.6 × 53.98mm ID-1 preset remains available in advanced settings. Source ratios differing from the frame are fitted with whitespace rather than clipping information. The quick A4 action updates the visible print configuration before producing the matching export.

Output names default to a local-calendar date and selected type, for example `PAN_Card_2026-11-22.pdf`. Users can edit the output filename. Results default to Govt IDs; the prominent PDF save action invokes `VaultBridge.saveFile()` and opens the existing unlock/review/encrypt flow. It does not silently save while locked. Cropped images also carry the Govt IDs destination in the shared Results actions.

TypeScript and 53 unit tests pass. Tests added for eight unique preset filenames, evidence-only prior ranking and non-overlapping rounded-ID1 A4 sizing. Browser scenarios cover the new selector/import flow, but browser execution and actual government PDF compatibility remain unverified in this environment. Existing synthetic geometry/layout/crypto tests are not proof of universal Aadhaar, PAN or other issuing-layout detection. No real identity documents were used. Arbitrary issuer-specific exact bounding zones are not hardcoded or advertised as verified. Review every crop and QR before printing.
